## Standing rules (every run)

1. **Never write any `scovox/build*` or `scovox/install*` base.** `install/` is
   the pinned mapper `de85263b3faf` (the only copy of that program); the seven
   `install_*` bases are pinned experiment builds. All builds go to scratchpad
   bases: `colcon build --build-base <scratch>/build_fix --install-base
   <scratch>/install_fix` from `scovox/`, and **assert the `Finished <<< pkg`
   lines are present** — colcon run from the wrong directory finds no packages
   and exits 0 silently.
2. **Live-box check before every run** (build, review dispatch, or launch edit):
   dump `ps aux` to a scratchpad file and inspect the file. Never put an
   experiment-script name in any command's argv — guard watchers match on argv.
   While any recording/campaign runs on this box: no builds, no launch-file
   edits, no ROS daemon disruption.
3. **Launch files are live in the pinned installs** (`--symlink-install`): an
   edit under `src/.../launch/` is an edit to what every pinned binary loads on
   its next launch. Launch edits are quarantined in Run 2 behind a guard/parser
   enumeration.
4. **Frozen invariants:** perf log tokens and their cadence (experiment parsers
   grep them); the per-ray timing-bracket scope (`tsdf_ms` = ray walks + carve
   flush, nothing else — the per-scan re-scope was tried and reverted as a
   defect); `batch_free_carve` semantics; wire gate-comparison values.
5. Commits only when the user asks. No AI attribution in any commit, doc, or
   file content.
6. Docs are updated in the same run the code lands (retractions/strikes first).

## Per-run protocol

1. Pre-flight: live-box check; record `git status` of both repos.
2. Implement the run's items.
3. Build to scratch bases; run the full gtest suite there. Baseline expectation
   149/149 plus any tests the run adds. Save the test log to scratchpad.
4. Save the cumulative `git diff` to scratchpad; the run's own diff is the delta
   against the previous run's saved diff.
5. **Adversarial review — a fresh agent, zero prior context.** The prompt must
   carry: the run diff (paths), the relevant audit items, the frozen invariants
   from rule 4, "verify against the code, not the author's summary", "answer
   'nothing' rather than pad", and read-only constraint. For Run 7, dispatch
   3–5 independent lenses instead of one agent.
6. Verify every load-bearing finding myself before acting on it. Confirmed
   findings are fixed and re-enter step 3.
7. Strike shipped items in the audit docs; append to the per-run log below.
   Stop — no commit unless prompted.
